# Баланс

Личный дневник питания, активности и самочувствия. Ведите записи по дням, задавайте цели и отслеживайте изменения за неделю.

| Версия | Где работает | Где хранятся записи | Напоминания |
| --- | --- | --- | --- |
| **Android** | Android 8.0 и новее, автономно | На телефоне | Системные уведомления, в том числе при закрытом приложении |
| **Веб** | В браузере на компьютере или телефоне | В SQLite на сервере, отдельно для каждого аккаунта | Звук и уведомления при открытом приложении |

В дневнике есть питание со справочником продуктов, расчётом калорий и БЖУ, рецептами и повтором приёмов пищи. Также можно записывать воду, шаги, тренировки, сон, привычки, вес и замеры. Раздел «Прогресс» показывает графики, итоги недели и историю измерений.

## Установка на Android

1. Скопируйте подписанный `Balance.apk` на телефон и откройте его в приложении «Файлы». APK можно [собрать из исходников](#сборка-android).
2. Если Android запросит разрешение на установку из этого источника, подтвердите его. Для обновления установите APK поверх предыдущей версии с той же подписью.
3. После установки откройте **Напоминания → Разрешить уведомления**. Если видна кнопка **Разрешить точное время**, включите этот доступ, чтобы Android реже задерживал сигнал.

Приложение работает без аккаунта, интернета и сервера. Расписание восстанавливается после обычной перезагрузки и разблокировки телефона. Если в настройках Android нажали «Принудительно остановить», снова откройте «Баланс», чтобы возобновить напоминания.

### Перенос записей и резервные копии

- Чтобы перенести записи из веб-версии, откройте **Настройки → Копия дневника → Экспортировать данные**. Передайте JSON-файл на телефон и выберите **Настройки → Копия дневника → Импортировать JSON**.
- Импорт добавляет записи к дневнику. При повторном импорте одинаковые записи пропускаются.
- Для резервной копии на Android выберите **Настройки → Копия дневника → Экспортировать данные**. Храните копию отдельно от телефона, если хотите восстановить записи после удаления приложения или смены устройства.

Android-дневник и веб-аккаунт ведутся отдельно. Записи переносятся через JSON вручную.

## Запуск веб-версии

Нужен **Node.js 24 или новее**. В Windows можно дважды нажать [`start.bat`](start.bat). Скрипт использует `runtime/node.exe`, если файл есть, или Node.js из `PATH`.

Из терминала в папке проекта:

```bash
node server.js
```

Откройте [http://localhost:3000](http://localhost:3000), создайте аккаунт и настройте дневные цели. Оставьте сервер запущенным, пока пользуетесь дневником.

### Доступ с телефона по Wi‑Fi

Подключите телефон и компьютер к одной сети. Если сервер уже запущен, остановите его и запустите из PowerShell в папке проекта:

```powershell
$env:HOST = '0.0.0.0'
.\start.bat
```

Посмотрите IPv4-адрес компьютера командой `ipconfig` и откройте на телефоне `http://<IPv4-адрес>:3000`. Если страница не открывается, проверьте доступ Node.js в брандмауэре Windows для частной сети.

Для установки веб-версии на главный экран используйте сайт по HTTPS. На iPhone этот пункт находится в меню «Поделиться» в Safari. Просмотр и изменение записей в веб-версии требуют доступа к серверу.

### Запуск в Docker

```bash
docker build -t balance .
docker run --rm --name balance -p 127.0.0.1:3000:3000 -v balance-data:/app/data balance
```

Откройте [http://localhost:3000](http://localhost:3000). Именованный том `balance-data` сохраняет базу между запусками. При запуске напрямую база находится в `data/balance.sqlite`. Для полной резервной копии остановите сервер и скопируйте каталог `data/` целиком. Через веб-интерфейс можно экспортировать записи отдельного аккаунта в JSON.

| Переменная | Назначение | Значение по умолчанию при прямом запуске |
| --- | --- | --- |
| `HOST` | Адрес, на котором слушает сервер | `127.0.0.1` |
| `PORT` | Порт HTTP | `3000` |
| `COOKIE_SECURE` | Значение `1` добавляет флаг `Secure` к cookie сессии | Не задана |

Перед публичным размещением настройте HTTPS, `COOKIE_SECURE=1`, ограничение частоты входа и регистрации и резервное копирование. Восстановление пароля в веб-версии пока отсутствует.

## Сборка Android

На Windows установите JDK 21 и пакеты Android SDK `platforms;android-35` и `build-tools;35.0.0`. Укажите пути к JDK и SDK в `JAVA_HOME` и `ANDROID_HOME` либо передайте их скрипту через `-JdkHome` и `-SdkRoot`.

Если у вас ещё нет ключа подписи, создайте его один раз. `keytool` запросит пароль хранилища:

```powershell
$keyDir = Join-Path $env:USERPROFILE 'balance-keys'
New-Item -ItemType Directory -Path $keyDir -Force | Out-Null
$key = Join-Path $keyDir 'balance.p12'
& "$env:JAVA_HOME\bin\keytool.exe" -genkeypair -storetype PKCS12 -keystore $key -alias balance -keyalg RSA -keysize 2048 -validity 10000 -dname 'CN=Balance Android'
```

Соберите APK, указав существующее хранилище ключа:

```powershell
.\android\build.ps1 -Keystore "$env:USERPROFILE\balance-keys\balance.p12"
```

Скрипт создаёт `Balance.apk` в текущей папке и проверяет подпись. Для другого пути используйте `-OutFile`. Пароль можно ввести при подписи или передать через `BALANCE_ANDROID_KS_PASS` для текущего процесса. Храните ключ и пароль вне репозитория. Для выпуска обновлений используйте ключ, которым подписана установленная версия.

## Тесты

Для полного прогона нужны Node.js 24+ и npm:

```bash
npm ci
npx playwright install chromium
npm test
```

На Windows браузерные тесты используют установленный Edge при наличии. Путь к браузеру можно задать через `BROWSER_PATH`. `npm test` проверяет HTTP API, сценарии веб-дневника и работу автономного интерфейса в браузере. Для отчёта о покрытии выполните `npm run test:coverage`. Серверные тесты используют SQLite в памяти и запускаются отдельно командой `node --test test.js records.test.js`.

## Структура проекта

- [`public/`](public/) — общий интерфейс и сервис-воркер веб-версии.
- [`server.js`](server.js) — HTTP API, аккаунты, сессии и база SQLite.
- [`android/`](android/) — Android-оболочка, локальное хранилище IndexedDB, системные напоминания и сборка APK.
- [`.github/workflows/ci.yml`](.github/workflows/ci.yml) — тесты, проверка запуска Docker и публикация контейнерного образа в GHCR при отправке версионного тега.
