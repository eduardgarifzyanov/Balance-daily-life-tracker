# Баланс

Приложение для отслеживания питания, активности и самочувствия. Node.js 24+, SQLite, HTML/CSS/JavaScript; без внешних зависимостей для запуска и без сборки.

## Запуск

Дважды нажмите `start.bat`, оставьте окно открытым и перейдите на http://localhost:3000. Либо выполните `node server.js` в папке проекта. Создайте аккаунт и настройте личные цели.

Серверные тесты: `node --test test.js records.test.js`. Для проверок в браузере установите зависимости командой `npm install` и запустите `npm test`. На Windows тесты используют Edge при наличии. Можно задать путь к браузеру через `BROWSER_PATH` или установить Chromium командой `npx playwright install chromium`. Тесты работают с SQLite в памяти.

База хранится в `data/balance.sqlite`. Для резервной копии остановите сервер и скопируйте папку `data` целиком. Не публикуйте её в Git.

## Возможности

- Регистрация, вход, выход, отдельные записи для пользователей; пароли хешируются scrypt, сессия — HttpOnly cookie на 30 дней.
- Дневник по датам, питание со справочником и ручным вводом, пересчёт калорий и БЖУ по массе порции.
- Вода, шаги и тренировки с ручным вводом, сон с оценкой качества, отметки привычек, вес и окружности, график последних 14 замеров.
- Настройка целей, удаление записей, экспорт своего дневника в JSON.
- Напоминание о воде через 30 минут при открытой вкладке, адаптивный интерфейс и PWA manifest.

## Телефон и установка

Для проверки в одной Wi-Fi сети задайте в PowerShell `$env:HOST='0.0.0.0'; node server.js` и откройте на телефоне `http://IP-компьютера:3000`. Может потребоваться разрешение входящего соединения в брандмауэре. Не используйте обычный HTTP для реальных паролей за пределами локальной сети.

Полноценная установка PWA на Android и iPhone требует HTTPS-хостинга. В Safari: «Поделиться» → «На экран Домой». На Android: меню браузера → «Установить приложение» или «Добавить на главный экран». Это веб-приложение, отдельных APK/IPA нет. Поддержка установки зависит от браузера. Сервер должен быть доступен телефону; автоматическое чтение датчиков не реализовано. После первой загрузки оболочка доступна без сети. Для просмотра и изменения записей нужен сервер. Когда связь вернётся, нажмите «Повторить».

## Архитектура и ограничения

`server.js` — HTTP API, статические файлы, SQLite и сессии. `public/app.js` — интерфейс и обработчики, `style.css` — адаптивные стили. API `/api/register`, `/api/login`, `/api/logout`, `/api/me`, `/api/records`. Все запросы записей ограничены текущим пользователем; запросы с посторонним Origin отклоняются.

Цели настраиваются пользователем; пищевые значения справочника можно уточнить по упаковке продукта. База продуктов небольшая; сканер штрихкода, распознавание фото, HealthKit/Health Connect, фоновые push и восстановление пароля не реализованы. Данные пользователей хранятся на одном сервере и доступны при входе с другого устройства; специального настольного клиента нет.

Для публичного размещения требуются HTTPS (`COOKIE_SECURE=1`), ограничение частоты входа/регистрации, подтверждение email, восстановление пароля, управление аккаунтом, политика обработки данных, резервные копии и мониторинг.
